VerbeFlow v0.2.1 simplifies appearance and reduces extension permissions.

- Removed screenshot-based page appearance detection, capture processing and tab inspection.
- Removed activeTab and optional website-access permissions. Required permissions are now storage, sidePanel and tts.
- Auto follows the browser/system light or dark preference. Manual theme choices, saved preferences and contrasting creator logos remain supported.
- Removed the experimental lifetime pricing proposal. The monthly Pro idea remains exploratory, with no checkout or subscription available.
- Updated privacy disclosures and added a redistribution review covering AGPL, Lefff LGPLLR and SIL OFL obligations.

The extension retains 110 six-tense learning entries with 660 bilingual examples, plus 7,666 additional reference entries with five simple tenses. Reference entries still lack reviewed auxiliary choices and examples; their passé composé remains unavailable.

Download **VerbeFlow-0.2.1.zip** to install. Unzip into a permanent folder, open `chrome://extensions`, enable Developer mode, choose Load unpacked and select the folder containing manifest.json. For an existing installation, close the panel, replace files in the same installed folder and click Reload on the extension card. Verify version 0.2.1. Earlier releases retain screenshot detection until updated.

The installer excludes development files but retains legal notices. The separate **VerbeFlow-0.2.1-source.zip** supplies complete corresponding source, resource inputs and modifications. Keep it available alongside the installer. SHA256SUMS supplies checksums.

Code remains AGPL-3.0-only; Lefff-derived data remains LGPLLR; fonts retain SIL OFL 1.1. Redistribution is subject to those licenses. No Chrome Web Store publication is performed.
