VerbeFlow v0.2.0 brings 7,776 French verbs to your browser side panel, available offline.

- 110 learning entries include six tenses, formation notes and 660 bilingual examples.
- 7,666 additional reference entries provide five simple tenses, with source and review status clearly displayed.
- Search infinitives or conjugated forms, choose among tense/person matches, and save up to ten verbs.
- Fixed light/dark palettes, French-voice pronunciation for learning examples, and a refined VerbeFlow logo.

Download **VerbeFlow-0.2.0.zip** below. Unzip it into a permanent folder, open `chrome://extensions`, turn on Developer mode, choose Load unpacked, and select the folder containing `manifest.json`. Pin VerbeFlow and click its toolbar icon to open the side panel. To update an existing installation, replace the files in its existing folder and click Reload on the extension card.

The download contains extension files, the user guide and required legal notices. The separate **source ZIP** is for contributors and anyone who needs the complete corresponding source and linguistic-resource materials. **SHA256SUMS** provides download checksums. GitHub’s automatically generated “Source code” downloads are also full repository snapshots, rather than the streamlined extension package.

Reference entries have not had an independent human language review. They do not yet include reviewed meanings, bilingual examples or auxiliary choices; passé composé is explicitly unavailable for these entries. Valid alternative spellings can be missing. The original 110 learning entries retain their six-tense coverage.

Chrome on macOS has been smoke-tested with the loaded extension. Other Chromium browsers and operating systems still need end-to-end verification. This GitHub release is not a Chrome Web Store listing.
