A FEW GOOD QUESTIONS

Before you
dive in.

What is VerbeFlow?

A French verb reference and learning extension that opens beside your webpage in a Chrome side panel.

Is it free? Do I need an account?

The current extension is free and requires no account. Download it from GitHub and load it manually using the installation guide.

Which browsers are supported?

Chrome 116 or newer is the documented baseline; loaded-extension checks have been performed on macOS. Edge, Brave, Vivaldi and desktop Chromium may work where extension side panels are supported, but are not verified end to end. Firefox, Safari and mobile browsers are not supported by this release.

Which French tenses can I explore?

The 110 learning entries cover présent, passé composé, imparfait, futur simple, conditionnel présent and subjonctif présent. The 7,666 additional reference entries cover the five simple tenses, without passé composé.

What is VerbeFlow Pro? When will it launch?

A proposed practice companion. Quizzes, flashcards and progress tracking are being explored. There is no committed launch date. Current free features, including ten saved verbs, are already available.

What happens to my data?

This website uses no analytics or email collection. The extension keeps saved choices locally. Auto appearance follows the browser or system theme without accessing webpage content. Read the privacy notice for details.
